Security Boundary — Local Storage Notice: Your API key is stored locally and unencrypted in chrome.storage.local inside your browser profile. It is never exposed to web pages or content scripts and is sent only to the Google Gemini API. However, local browser profile storage can be read by anyone with access to your OS user account or browser profile files. Stronger OS-level (Keychain/Credential Manager) or server-side key protection requires a local helper app (Native Messaging) or a backend proxy server.
